# 디지털 클래스 신청서 회원명단 연동 설정

이 자동화는 디지털 클래스 신청 Google Form(Form ID
`1DWtn1FQD86E4EHzABxeoEpHDuVeoFH_Smak4_C1RU7M`)의 **응답 스프레드시트**
("디지털 클래스 신청서(응답)")에 연결합니다.

입점 파트너 신청(`partner-form-auto-email.gs`)과 동일한, 이미 테스트된
연동 경로를 그대로 재사용합니다.

## 처음 한 번만 설정

1. "디지털 클래스 신청서(응답)" 스프레드시트를 엽니다.
2. `확장 프로그램 → Apps Script`를 엽니다.
3. 기본 코드를 지우고 `digital-class-application-forward.gs` 내용을 붙여넣어 저장합니다.
4. 스프레드시트를 새로고침합니다.
5. 상단 메뉴에서 `Harmony Link 자동화 → 1. 회원명단 연동 주소 저장`을 선택하고,
   회원가입 명단 Apps Script(`member-signup.gs`)를 배포했을 때 생성된 `/exec` 주소
   (`auth.js`의 `signupAutomationUrl`과 동일)를 입력합니다.
6. 상단 메뉴에서 `Harmony Link 자동화 → 2. 신규 제출 연동 시작`을 선택하고
   권한을 승인합니다. 이 함수는 실행할 때마다 기존 동일 핸들러 트리거를 먼저
   모두 제거한 뒤 정확히 1개만 다시 생성하므로, 여러 번 실행해도 중복
   트리거가 쌓이지 않습니다.

## 작동 방식

- **새 신청부터만** 자동 반영됩니다. 이미 접수된 과거 응답은 이 자동화로
  소급 처리되지 않습니다 -- 과거 데이터 반영은 별도의 수동 확인 작업입니다.
- 신청서의 `9.구글이메일`이 회원가입 명단의 이메일과 **대소문자 구분 없이
  정확히 일치**하는 기존 Harmony Link 회원이 있을 때만 그 회원의 상세정보와
  회원번호 상태(검정)가 자동으로 갱신됩니다.
- 이메일이 다르면 이름이 같아도 자동으로 연결하지 않습니다. 일치하는 회원이
  없으면 조용히 건너뜁니다(오류 아님) -- 새 회원 계정이나 회원번호가
  만들어지지 않습니다.
- 회원번호는 이 경로로 절대 재발급되거나 변경되지 않습니다. 이 스크립트는
  기존 신청서 메타데이터(이름/연락처/수강과목)만 갱신합니다.
- 동일 회원이 여러 번 제출해도 안전합니다(멱등적) -- 반복 제출은 최신 정보로
  다시 갱신될 뿐, 중복 레코드나 중복 회원번호를 만들지 않습니다.
