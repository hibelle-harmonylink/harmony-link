# 디지털 클래스 신청서 회원명단 연동 설정

이 자동화는 디지털 클래스 신청 Google Form(Form ID
`1DWtn1FQD86E4EHzABxeoEpHDuVeoFH_Smak4_C1RU7M`)의 **응답 스프레드시트**
("디지털 클래스 신청서(응답)")에 연결합니다.

입점 파트너 신청(`partner-form-auto-email.gs`)과 동일한, 이미 테스트된
연동 경로를 그대로 재사용합니다.

## 처음 한 번만 설정

1. "디지털 클래스 신청서(응답)" 스프레드시트를 엽니다.
2. `확장 프로그램 → Apps Script`를 엽니다.
3. 기본 코드를 지우고 `digital-class-application-forward.gs` 내용을 붙여넣어 저장합니다.
4. 스프레드시트를 새로고침합니다.
5. 상단 메뉴에서 `Harmony Link 자동화 → 1. 회원명단 연동 주소 저장`을 선택하고,
   회원가입 명단 Apps Script(`member-signup.gs`)를 배포했을 때 생성된 `/exec` 주소
   (`auth.js`의 `signupAutomationUrl`과 동일)를 입력합니다.
6. 상단 메뉴에서 `Harmony Link 자동화 → 2. 신규 제출 연동 시작`을 선택하고
   권한을 승인합니다. 이 함수는 실행할 때마다 기존 동일 핸들러 트리거를 먼저
   모두 제거한 뒤 정확히 1개만 다시 생성하므로, 여러 번 실행해도 중복
   트리거가 쌓이지 않습니다.
7. (선택) 상단 메뉴에서 `Harmony Link 자동화 → 응답 전체 왼쪽 정렬`을 한 번
   실행하면, 지금까지 쌓인 기존 응답 전체가 왼쪽 정렬로 맞춰집니다. 데이터
   값은 전혀 바뀌지 않고 정렬(서식)만 바뀝니다. 이후 새로 들어오는 응답은
   별도 실행 없이 자동으로 왼쪽 정렬됩니다.
8. (선택, 관리용 한글 이름 자동 연결을 쓰려면 필요) 상단 메뉴에서
   `Harmony Link 자동화 → 회원명단 시트 연결`을 선택하고, 회원가입 명단
   Spreadsheet의 URL 또는 ID를 입력합니다. 이 자동화 전용의 새 Script
   Property(`MEMBER_ROSTER_SPREADSHEET_ID`)에 저장되며, 1번 단계의
   `MEMBER_ROSTER_WEBAPP_URL`과는 별개입니다. 이 스크립트가 서버 내부에서
   그 Spreadsheet의 "이름"/"이메일" 컬럼만 직접 읽기 위한 용도로, 새로운
   공개 API를 만들지 않습니다.
9. (선택) 상단 메뉴에서 `Harmony Link 자동화 → 관리용 한글 이름 동기화`를
   실행하면, 기존 응답 전체를 검사하여 회원가입 명단과 이메일이 정확히
   일치하고 실제 한글 이름이 확인된 행에만 "관리용 한글 이름" 컬럼(없으면
   자동 생성)을 채웁니다. 원본 `4.이름`은 절대 수정되지 않습니다. 이후
   새로 들어오는 응답도 동일한 조건으로 자동 처리됩니다.

## 작동 방식

- **새 신청부터만** 자동 반영됩니다. 이미 접수된 과거 응답은 이 자동화로
  소급 처리되지 않습니다 -- 과거 데이터 반영은 별도의 수동 확인 작업입니다.
- 신청서의 `9.구글이메일`이 회원가입 명단의 이메일과 **대소문자 구분 없이
  정확히 일치**하는 기존 Harmony Link 회원이 있을 때만 그 회원의 상세정보와
  회원번호 상태(검정)가 자동으로 갱신됩니다.
- 이메일이 다르면 이름이 같아도 자동으로 연결하지 않습니다. 일치하는 회원이
  없으면 조용히 건너뜁니다(오류 아님) -- 새 회원 계정이나 회원번호가
  만들어지지 않습니다.
- 회원번호는 이 경로로 절대 재발급되거나 변경되지 않습니다. 이 스크립트는
  기존 신청서 메타데이터(이름/연락처/수강과목)만 갱신합니다.
- 동일 회원이 여러 번 제출해도 안전합니다(멱등적) -- 반복 제출은 최신 정보로
  다시 갱신될 뿐, 중복 레코드나 중복 회원번호를 만들지 않습니다.
- 새 응답이 제출되면 그 행 전체가 자동으로 왼쪽 정렬됩니다. 이 정렬 처리와
  회원명단 연동은 서로 독립적으로 동작합니다 -- 한쪽이 실패해도 다른 쪽
  처리에는 영향을 주지 않습니다. 정렬은 서식만 바꾸며 값은 절대 바꾸지
  않습니다.
- "관리용 한글 이름"은 회원가입 명단의 "이름" 값에 실제 한글 문자가 있을
  때만 채워집니다. 영문만 있는 이름(예: 로마자 표기)이거나 이메일이
  일치하는 회원이 없으면 빈칸으로 남고, 이름만 보고 추측하거나 영문을
  한글로 임의 변환하지 않습니다. 이 동기화 역시 정렬·회원명단 연동과
  독립적으로 동작하며, 회원명단 시트 연결이 아직 안 되어 있어도 다른 두
  기능은 계속 정상 작동합니다.
